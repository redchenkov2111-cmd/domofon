# 🚪 Домофон — Микросервисное приложение

Полнофункциональная система «умного домофона» с возможностью звонить жильцам, принимать и отклонять звонки в реальном времени, вести историю с таймером и логировать все системные события.

Проект полностью контейнеризирован, работает за реверс-прокси Nginx с поддержкой **HTTPS** и защищенного **WebSocket (wss)**.

---

## 🌟 Основные возможности

- **Аутентификация и авторизация**: JWT-токены, роли (Администратор и Житель).
- **Управление пользователями**: Администратор может добавлять, редактировать и удалять жителей.
- **Разделение по адресам**: Жители видят в списке для звонков только соседей по своему дому. Администратор видит всех и может фильтровать по адресу.
- **Звонки в реальном времени**: Мгновенные уведомления о входящем звонке через WebSocket (паттерн Observer).
- **Управление вызовом**: Принять, отклонить, завершить звонок. Отображение времени разговора (живой таймер) и звуковое оповещение.
- **История звонков**: Кэширование последних запросов в Redis для ускорения работы.
- **Централизованное логирование**: Отдельный микросервис собирает логи всех действий в базу данных.
